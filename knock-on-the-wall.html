Knock on the wall

An ordinary program is walled off from the machine’s dangerous powers: it cannot touch the disk, the screen, or another program’s memory directly. Only the kernel can, and a single bit in the processor decides who you are. Try to break out, then ask nicely instead.

Your program (user mode)

It can do arithmetic and touch its own memory. For anything else, it must go through the kernel.

The kernel (privileged mode)

The only code allowed to touch hardware. It runs with the privilege bit set to 1, checks every request, and does the dangerous part on your behalf — or refuses.

The stack and the overwrite

Every time a routine calls another, the processor needs somewhere to remember where to come back to. That somewhere is the stack, and it is just ordinary memory. First watch it grow and shrink during a recursive call. Then see what happens when a program writes past the end of its own local array.

void greet(char *name) {
    char buffer[8];          // lives in this routine's stack frame
    strcpy(buffer, name);    // copies name, and its end-marker, with no length check
    printf("Hello, %s\n", buffer);
}                            // ← returns to the address saved beside the buffer

Same bytes, five readings

Sixteen bytes. Nothing else. Below them, the same bytes read five different ways at once: as whole numbers, as text, as a decimal number, as a picture, and as instructions for the Bench Computer. Change any byte and every reading changes. Which one is the true meaning?

Byte order for multi-byte numbers:

1 · Whole numbers

2 · Text (ASCII / UTF-8)

3 · Decimal numbers (floating point)

4 · A picture

5 · Instructions for the Bench Computer

Top four bits: which instruction (LDA, ADD, SUB, STA, LDI, JMP, JC, JZ, OUT, HLT). Bottom four: the address or number it works on.
